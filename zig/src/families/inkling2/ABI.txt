zig/kernels/cuda/inkling2_quant.cu:1
Inkling2 quantized expert path, bringup kernels: BF16 dense matvec, NVFP4 (four-over-six MAE)
and MXFP8 activation quantize/dequantize, and the matching quantized matvec over stored expert
weights. Activations are fp32 arrays holding BF16-rounded values; weights are the checkpoint's
stored row-major bytes. Bringup kernels, not a qualified serving path.

Compile without fast math and without ftz: subnormal fp32 intermediates (1 / FLT_MAX etc.) must
survive. Every arithmetic step of the quantization formulas is an explicit __f*_rn intrinsic, so
fmad contraction cannot change a rounding; the matvec sums likewise use __fadd_rn(__fmul_rn()).

The equations are the deployment reference's quantization formulas (speed-overlay inkling2
ops/nvfp4.py, four-over-six MAE scale choice, and ops/mxfp8.py, ceil-power-of-two ue8m0 block
scales, Apache-2.0); this is an independent TensorFold implementation of those equations.

zig/kernels/cuda/inkling2_quant.cuh:1
ABI of the Inkling2 quantized expert-path bringup kernels (inkling2_quant.cu).
Bringup kernels, not a qualified serving path; no release qualification is claimed.

Compile the .cu without fast math and without ftz (subnormal fp32 quantization intermediates
such as 1 / FLT_MAX must survive). All quantization arithmetic uses __f*_rn intrinsics, so fmad
contraction cannot alter a rounding; the reductions are fp32, never half.

Layouts follow the checkpoint's target weight schema: NVFP4 experts store w13 as U8
[experts,4608,2304] (K = 4608 hidden, two e2m1 nibbles a byte, low nibble first) with e4m3
block scales [experts,4608,288] (K/16) and per-expert fp32 amax plus one fp32 denominator;
w2 is [experts,4608,1152] (K = 2304) with scales [experts,4608,144]. MXFP8 experts store
w13 as E4M3 [experts,4608,4608] with ue8m0 scale bytes [experts,4608,144] (K/32); w2 is
[experts,4608,2304] with scales [experts,4608,72]. Gate/up rows stay interleaved as stored.

zig/kernels/cuda/inkling2_quant.cuh:28
One row: y[K] = dequantize(quantize(x[K])), reconstructed fp32 values, never re-rounded to
BF16. Grid [1], block 256, shared 19 KB (the row is staged in shared memory). Admitted
dimensions: K % 32 == 0 and K <= 4608 (served rows are 4608 and 2304); the amax spans the
whole row. format 0 = NVFP4 four-over-six MAE, 1 = MXFP8.

NVFP4: per-token scale 1536/amax; each 16-input block tries 6.0- and 4.0-based e4m3 block
scales (products capped at 448 before the e4m3 round), e2m1 codes rounded to nearest with
ties to the even code and saturation at 6, and keeps the candidate whose absolute
reconstruction error, summed pairwise over 4 tree levels, is smaller (ties keep 6.0). An
all-zero row reconstructs to all zeros. MXFP8: block 32, ue8m0 scale ceil(amax/448) to a
power of two clamped to exponent 254, 2^-127 subnormal minimum at exponent 0, e4m3 codes
rounded to nearest saturating at +-448.

NaN policy: any nonfinite input NaNs the entire output row (explicit propagation); finite
rows produce only finite arithmetic except documented saturation.

zig/kernels/cuda/inkling2_rows.cuh:1
Inkling-2 one-token bringup row kernels: exact ABI and launch contracts (inkling2_rows.cu holds the
implementations, written from the reference equations; every kernel is deterministic: no atomics, no
allocator, fixed launch, fp32 sums in a fixed order and one BF16 rounding at each stated boundary).

Common conventions
  * Activation arrays are float but hold BF16-rounded values where a boundary says so: an output
    written "BF16" is __float2bfloat16_rn(value) widened back to float, one rounding, ties to even.
  * A "BF16 row" weight is uint16_t BF16 bits widened exactly (__bfloat16asfloat), never re-rounded.
  * Reductions: each thread sums its strided elements ascending, a warp xor tree, then warp partials
    in warp order. Same launch -> same bytes, run to run.
  * Non-finite inputs are never masked: NaN/Inf flow through the formula (fmaxf keeps the finite side
    of a max, a NaN sum stays NaN), except tf_ink2_route, which is fail closed (below).
  * Pointers are non-aliasing unless a kernel says otherwise; nothing is written in place.
  * Grid/block: every kernel takes 256 threads a block (__launch_bounds__(256)); per-kernel grids and
    static shared bytes are listed per kernel. Launch at other widths is not part of the contract.

(2) Depth attention over finished blocks plus the partial residual, one token: rows d in [0, depth)

zig/kernels/cuda/inkling2_rows.cuh:38
(3) Short causal convolution, taps 0..3, one token: hist[3 * H] holds the RAW previous inputs
    ordered previous1, previous2, previous3 (lag 1..3); x[H] is the current token; lag 0 is x itself.
    y[c] = BF16((x[c] + sum_{lag 0..3} tap[lag][c] * x[c - lag]) / divisor), the residual x added
    once on top of the lag-0 tap, taps summed ascending. After every old value is read the history
    shifts one row and stores the RAW x: previous3 drops, previous2 -> 3, previous1 -> 2, x -> 1;
    a thread touches only its own channel, so x, y and hist must not alias.
    Tap layouts (checked against the checkpoint schema and the CPU reference):
      shared_taps == 0 (static, divisor sqrt(5)): w is the BF16 [H,4] channel-major conv weight and
        the tap is REVERSED: lag L reads w[c * 4 + (3 - L)], so lag 0 reads index 3.
      shared_taps != 0 (dynamic, divisor 3): w is the BF16 [4,H] lag-major static_w read DIRECTLY,
        w[L * H + c]; dyn is nullable [H/head_dim, 4] fp32 precomputed taps, dyn[h * 4 + L] with
        h = c / head_dim, also DIRECT lag (weight_proj row h * 4 + L); tap = static + dyn.
    Grid (1,1,1), block 256, no shared. H >= 1. In static mode dyn is ignored (pass nullptr).
    shared_taps != 0 with dyn != nullptr needs head_dim in [1, H] dividing H; otherwise y is the
    quiet NaN 0x7fc00000 and the history is left untouched.

zig/kernels/cuda/inkling2_rows.cuh:66
(6) Router, one token: logits[E] fp32 (router projection output), bias[E] fp32 (required).
    score[e] = sigmoid(logits[e]); picks are the topk maxima of score[e] + bias[e], ties to the
    LOWER expert id, taken in descending order; the selection weight is the UNBIASED score:
    weights[k] = scale * score[ids[k]] / (sum of the picked scores + 1e-20), the sum accumulated in
    pick order. Grid (1,1,1), block 256, 10304 B shared. Valid shapes: E in [1, 2048], topk in
    [1, 32] with topk <= E. Fail closed, never a silent mask: any non-finite logits[e] or bias[e],
    or any invalid shape, writes ids[k] = -1 and weights[k] = quiet NaN 0x7fc00000 for
    k < min(topk, 32) (topk <= 0 writes nothing) and selects nothing.

CPU reference scope
Independent CPU equation oracle for Inkling2's first layer, from unchanged HF safetensors.

This development reference imports NumPy, never CUDA, Torch or the tested native implementation.
Projection/attention/residual sums use float64. Checkpoint quantization and BF16 boundaries are explicit.
It models EP4 with whole experts and the routing weight applied before the down activation quantization.
